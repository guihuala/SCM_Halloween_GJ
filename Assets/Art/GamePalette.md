# 全游戏统一色卡

色卡资源：`Assets/Resources/NightVoyage/Palette.asset`，可在 Unity Inspector 中编辑。主菜单、HUD、弹窗、货物卡、提示、交互反馈、地图和角色姓名强调色共用该资源；UI 重建后也会重新接入。

| 色名 | HEX | 用途 |
| --- | --- | --- |
| Night | #172128 | 背景、深色字、纸面上的文字 |
| Panel | #24323A | 深色界面层级与背景分隔 |
| Raised | #32454B | 深色菜单按钮与进度轨道 |
| Paper | #F1E7D2 | 浅色弹窗、tooltip、对话及教学底色；深底正文 |
| Muted | #B5C3BA | 次级文字、说明 |
| Mint | #9AD5BA | 主要操作、绿色悬停路径、成功反馈 |
| Gold | #E9B46C | 所选目的地、提醒、当前节点 |
| Heat | #DE9185 | 高温路段、角色强调色 |
| Water | #87BFCC | 积水路段、角色强调色 |
| Rough | #C4AA79 | 颠簸路段、角色强调色 |
| Lavender | #B7A5CD | 角色姓名强调色 |
| Road | #7D9891 | 普通路段、节点与边线 |

主要按钮使用薄荷绿底与深色字；次级按钮使用 Raised 底与暖纸白字。纸片插画上的文字使用深色。不可用状态采用降低明度与透明度，保持按钮原本的含义。高温、积水、颠簸仍有对应路线说明，颠簸继续使用虚线。

半透明遮罩、地图区域、悬停与按压状态由色卡中的基础色派生。原始手绘PNG、角色头像、货物、载具和地标的像素不变；配色通过组件乘色和共享规则应用，保留手绘笔触。

`Tools > Night Courier > Apply Unified Game Palette` 重新应用到场景和面板，并检查正常按钮的文字对比度。常用正文、次级文字、主要按钮和提醒文字的对比度为5.50:1–13.31:1。每次修改色卡后重新执行此入口，并重新进入试运行查看效果。

色卡图导出到 `ArtPreviews/game-palette.svg`，配套PNG为 `ArtPreviews/game-palette.png`。

对话框使用不透明的暖纸白底与深色正文、深色角色姓名；教学条使用纸白混合10%薄荷绿的浅色底、深色文字。阅读区域不透出地图细节，继续和跳过按钮沿用薄荷绿。

所有弹窗、tooltip、目的地卡和货物卡采用不透明的浅纸色底与深色文字，浅色界面中的次级按钮使用纸白与灰绿混合色。对话框1840×260、正文36号，教学框1440×152、标题30号、说明28号；选路教学移至底部，打开货物抽屉时回到顶部，避开操作目标。地图幽灵使用 `Assets/Resources/NightVoyage/VehicleIcons/Ghost_.png`，由地图移动标记的 `ghostArtwork` 指定；其他载具绑定不变。
