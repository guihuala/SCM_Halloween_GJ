# 地图占位资产与重绘交接

本包对应当前游戏的 **6个角色节点、8条道路**，不是新增地图规则。保留已有货物/载具图标的深色圆角描边、奶油白、薄荷绿、暖金与淡紫。当前交付为独立资产包；没有自动替换游戏中的地图或改变布局。

## 从哪张图开始画

- `Sources/map_master.svg`：整片地图的可编辑母版。分组为 `01-terrain`（地形）、`02-roads`（道路）、`03-landmarks`（地标）。这是主要重绘文件。
- `Sources/map_guide.svg`：增加节点编号、中文名称、红色锚点十字与精确坐标的参考母版。红色坐标是制作标记，不进入正式游戏。
- `Textures/map_master.png`：无文字、无坐标的整图合成预览。
- `Textures/map_guide.png`：带标注的整图参考，便于沟通与描图。
- `Sources/terrain.svg` / `Textures/terrain.png`：只有地形的底图，不含可交互道路、地标或文字。
- `Sources/roads.svg` / `Textures/roads.png`：透明背景的静态道路参考层。
- `Landmarks/`：6个地标，各有独立透明SVG与PNG。
- `FX/`：7个独立、透明、可染色的动效占位素材。
- `map_layout.json`：节点位置、8条边、道路类型与地标锚点，给程序接入时使用。
- `motion_preview.html`：自包含、离线可打开的动效示意，可暂停、切换线路与调整演示速度。它是美术预览，不运行订单、事件或载具规则。

## 重绘尺寸与锚点

整图画布为 **2070×1200**，恰好是当前地图参考坐标系690×400的3倍。坐标原点在左上，X向右、Y向下。

| ID | 地标 | 像素锚点 X,Y | 透明地标源文件 |
|---|---|---|---|
| 0 | 废弃地铁站 / 黑暗精灵 | 265.5, 615 | `00_abandoned_subway.svg` |
| 1 | 前房车露营基地 / 狼人 | 661.5, 309 | `01_forest_campsite.svg` |
| 2 | 蜂蜜酒地窖 / 小熊 | 661.5, 921 | `02_mead_cellar.svg` |
| 3 | 废弃广播塔 / 吸血鬼 | 1140, 870 | `03_radio_tower.svg` |
| 4 | 博物馆废墟 / 僵尸 | 1288.5, 309 | `04_museum_ruins.svg` |
| 5 | 人类聚居地酒吧 / 女巫 | 1701, 615 | `05_settlement_bar.svg` |

每个地标的源画布为256×256，脚底锚点为左上坐标 **(128,216)**。Unity Sprite Pivot 对应 **(0.5,0.15625)**；已随占位PNG导入设置保存。重绘时保持透明边距、画布和锚点一致，就不必重新校对节点。

当前 `Stops.csv` 的 x/y **不是**可直接贴图的0–1坐标。程序使用：

```
x_px = (50 + stop.x × 550) / 690 × map_width
y_px = (35 + stop.y × 340) / 400 × map_height
```

例如地铁站的 stop.x=0.07，实际落点是图宽的约12.83%，不是7%。JSON已记录换算后的归一化位置。

地图区域会随分辨率、对话框显示而改变长宽比。推荐：**底图伸展填满地图容器，地标独立使用 Preserve Aspect，按上述公式定位**。不要把六个地标烘焙进背景后再强行横向拉伸，否则建筑也会变形。整图合成图主要用于参考重绘。

## 现在这些动效需要什么资产

当前 `CourierRouteGraphic` 已在代码中绘制路网、路径颜色、移动光点与呼吸圆环，**原样保留这些效果时，不需要额外制作序列帧**。美术重点是底图与地标；下面的FX是以后把程序几何替换成贴图时可选用的占位件。

| 效果 | 需要绘制的东西 | 本包素材 | 程序负责的动作 |
|---|---|---|---|
| 移动光点 | 一张白色圆点，透明背景 | `traveler_core` 64×64 | 沿当前路段起终点插值位置，以薄荷绿染色 |
| 呼吸光晕 | 一张软边白色圆光，透明背景 | `traveler_halo` 128×128 | 缩放/透明度周期变化，和光点一起移动 |
| 当前站点 / 选中节点 | 白色空心圈、圆点或定位标记 | `node_ring` 128×128、`node_disc` 64×64、`current_pin` 128×128 | 改色、显示隐藏或轻微脉冲 |
| 已选路线 | 不要画进背景；保留代码道路，或用可拉伸白色线段 | `route_stroke` 128×128（有效线宽12，主体长120） | 按路径改变颜色，旋转、拉伸到节点之间 |
| 已走路段延伸 | 共用上述线段，不另画整条“行驶中”路线 | `route_stroke` | 终点跟随进度；开始位置固定在出发节点 |
| 碎石虚线 | 单独一截白色短线 | `road_dash` 64×64 | 沿道路重复摆放，仍可改色 |
| 建筑/节点按钮反馈 | 地标正常图即可 | 6张地标PNG | 悬停改色或轻微缩放，点击回弹 |
| 弹窗滑入/按钮反馈 | 不需要新地图图片 | 沿用现有UI | 现有UI动画继续负责 |

FX素材是**静态单张**，不要把光点、光晕、路线高亮或文字合成进地形图。`traveler_halo` 本身是柔光渐变，比当前纯色半透明圆更柔和；要完全一致可继续保留原来的程序圆形。

现有效果的代码参数：光点半径7，外圈半径 `13 + sin(VisualTime × 3) × 1.5`，周期约2.09秒；已走路段和光点为薄荷绿，选中路线为橙色。这里的半径以地图UI单位计，**不是PNG源文件像素**。换成贴图后要按视觉尺寸设置Image矩形，不能直接把128×128的光晕原尺寸放进去。

行驶进度当前按整数回合结算。想让光点在回合之间连续滑动，只需给显示位置增加插值，不需要重画地图，也不要改变订单回合数。暂停时地图光点和呼吸应冻结；菜单按钮仍可保留独立于游戏时间的UI反馈。

## 推荐接入层级

```
Map（沿用当前地图容器）
  TerrainImage             // terrain.png；拉伸；不接收点击
  RuntimeRoadGraphic      // 沿用 CourierRouteGraphic 的道路、选中路线与进度
  LandmarkImages          // 六张独立地标；保持比例；不接收点击
  NodeButtonsAndLabels    // 沿用节点按钮、地点名和订单提示
  OptionalMotionSprites   // 仅当改为贴图动效时使用；不要和程序光点重复显示
```

如果背景画入了静态道路，必须让程序的默认道路底线与之统一，或隐藏一份；不要同时显示两套偏移的道路。`roads.png` 是对齐参考，不是要求在当前代码上再叠一遍。不要根据静态图猜位置，应使用JSON或同一节点坐标公式。

## 正式美术最少交付

1. 1张纯地形底图（2070×1200，或同长宽比更高分辨率）。
2. 6张透明地标（每张256×256或512×512；同一脚底锚点，整体放大时锚点也等比例放大）。
3. 现有角色、货物、载具图标继续沿用。
4. 选择保留当前程序动效，则无需新增光效图；选择贴图版，则重绘圆点/光晕/节点圈即可，另外4张FX可按需要沿用或忽略。

所有动效占位PNG均有透明背景；只有地形和整图合成PNG为不透明底图。没有把天气变化、逐帧建筑动画或车辆八方向动画设为必需项，因为当前地图动效不依赖它们。
